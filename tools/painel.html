Como o link de afiliado entra na vitrine

O Mercado Livre não tem API oficial de afiliado — não existe um jeito oficial de o site gerar o link sozinho. Então aqui vão os dois caminhos que funcionam.

✅ Caminho A — em lote pelo painel do ML (recomendado, 100% dentro das regras)
  1. Clique em Exportar lista abaixo e copie o texto.
  2. Abra afiliados.mercadolivre.com.br → Ferramentas → Gerador de links.
  3. Cole todas as URLs de uma vez (o gerador aceita várias linhas), escolha a etiqueta e clique em Gerar.
  4. Copie os links gerados (mercadolivre.com/sec/…) e cole no campo de importar.

A importação casa os links pela ordem, então exporte e importe sem mexer na lista.

⚙️ Caminho B — a ferramenta monta o link sozinha (matt_word + matt_tool)

Todo link do programa de afiliados carrega seus parâmetros matt_word e matt_tool. Se você ensinar os seus para a ferramenta, ela monta os próximos links sozinha, sem abrir o painel.

Como ensinar: gere um link no painel do ML, cole no campo abaixo e clique em Aprender.

⚠️ Isto usa um formato não documentado pelo ML. Funciona, mas confirme com uma venda de teste antes de depender só dele. O Caminho A é o garantido.
